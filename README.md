# Nora

**An independent AI application and language model project.**

Nora is an experimental AI project focused on building a custom language model, local inference runtime, and conversational AI application.

## Project Goals

- Develop a language model trained from scratch.
- Explore Turkish and English language support.
- Build a local CPU-compatible inference runtime.
- Integrate model responses into the Nora chat application.
- Develop reproducible training and evaluation pipelines.
- Improve conversational quality through carefully evaluated experiments.

## Current Status

Nora is under active development.

The project includes an experimental model-training pipeline, tokenizer, checkpoint system, Python inference runtime, and web-based chat application.

The current model is an early prototype and has not yet demonstrated reliable conversational ability.

## Development Principles

- Preserve dataset provenance and attribution.
- Review licensing and data-use requirements before training.
- Validate checkpoints and model configurations.
- Keep training and inference systems separate.
- Evaluate actual model behavior before claiming capabilities.
- Protect user data, credentials, and private project files.

## Data and Licensing

Third-party datasets and model artifacts require appropriate source attribution and license review.

A dataset's public availability does not automatically establish permission to use every record for training. Data acquisition, processing, and training require separate review.

## Security

Never commit API keys, passwords, `.env` files, personal information, private datasets, or unreviewed model artifacts.

## Disclaimer

Nora is an experimental research and development project. It is not currently presented as a production-ready general-purpose AI model.
